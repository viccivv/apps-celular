    Sobre este app

    Este é um projeto de exemplo feito com HTML, CSS e JavaScript puro, para a disciplina de Desenvolvimento Mobile.

    Manipulação do DOM, eventos, delegação de eventos, estado em memória, persistência com localStorage e navegação entre telas sem recarregar a página (como uma SPA).
